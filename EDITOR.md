# ACL: аудиоредактор (первая реализация)

Редактор использует недеструктивные клипы: файлы остаются на диске без изменений.
Дорожка `Original` теперь редактируется на тех же условиях, что и Clean:
допускаются разрезание, fade, смещение, переименование и эффекты.
Видео используется как беззвучный источник изображения и времени,
а звук всех клипов идёт через независимые аудиоплееры и микшер.

## Инструменты

- **Мышь** (`V`) — перемещение аудиоклипов и редактирование их параметров.
- **Лезвие** (`B`) — клик по любому аудиоклипу, включая Original;
  режет в точке курсора. Два фрагмента остаются **на одной дорожке**.
  Ближе 100 мс от края клипа разрез не производится.
- **Fade in/out** — верхние ручки регулируют длительность затухания;
  круглый маркер на кривой регулирует её изгиб вверх/вниз. Огибающая
  меняет также высоту самой волны. Без дополнительного изгиба используется
  `afade=curve=qsin`, с изгибом — вычисляемая огибающая FFmpeg.
- **Усиление отдельного клипа** — наведи на волну: снизу появится
  круглый маркер под курсором. Вертикальный drag меняет уровень до 200%,
  мгновенно меняя форму волны. Двойной щелчок возвращает 0 dB.
- **Бесшовный разрез** — соседние части одного источника используют
  один аудиотранспорт, без переключения HTMLAudioElement на границе.
  Если источник или позиции не совпадают, клипы воспроизводятся отдельно.
- **Громкость клипа** — перетащите горизонтальную линию внутри клипа
  вверх или вниз (0–200%).
- **Громкость дорожки** — маленький ползунок слева. Также можно использовать
  фейдер в микшере. Громкость общая для всех фрагментов одной дорожки.
- **Имя дорожки** — двойной щелчок по её названию слева, ввод, Enter.
  Escape отменяет переименование.
- **Порядок дорожек** — перетащите их за область слева с символом захвата.
  Пустая строка «Новая Clean» всегда остаётся внизу.
- **Удаление** — клавиша `Delete` удаляет выделенный клип или дорожку.
  Доступно также контекстное меню.
- **Синхронизация** — перемещение клипа мышью либо двойной щелчок и точный
  ввод смещения в секундах с шагом 0,001.
- **Повторная нейросетевая очистка** — пустая последняя строка с кнопкой
  «Обработать видео». Shift + перетаскивание по шкале выбирает фрагмент
  для циклического воспроизведения/обработки.
- **Масштаб** — Ctrl/Cmd + колесо над таймлайном для горизонтального
  масштаба, Alt + колесо для высоты дорожек.
- **Навигация таймлайна** — обычное колесо прокручивает дорожки вертикально
  даже при наведении на звуковую волну; Shift + колесо двигает по времени.
  Линейка с отметками и таймкодами закреплена сверху, горизонтальный
  скроллбар всегда находится внизу панели и не уезжает с дорожками.
  При масштабировании оба направления синхронизированы.
- **Ctrl+Z / Ctrl+Y / Ctrl+Shift+Z** — отмена и возврат правок.
  Перетаскивание клипа/ручки fade составляет одну историю действия.
- **Ctrl+C / Ctrl+X / Ctrl+V** — копировать, вырезать и вставить выделенный
  аудиоклип; вставка происходит на текущую позицию каретки.
- **Shift + лезвие** — одним действием разрезает все пересекаемые
  аудиоклипы в момент курсора. Видео не разрезается.
- **Свойства и эффекты** — контекстное меню дорожки слева. Настройки
  `Постобработка` и `Фильтры` обрабатываются через отдельный FFmpeg
  проход, результат создаётся новым WAV. Не удаляются предыдущие версии;
  Undo либо «Сбросить эффекты» возвращают исходник.
- **fx** — закреплённый индикатор справа от дорожки после обработки,
  по клику открываются свойства.
- **Линейка** — закреплена по горизонтали: клик по видимой шкале
  перематывает воспроизведение независимо от zoom/scroll.


## Проекты ACL (.aclproj)

- `Ctrl+S` — сохранить текущий проект. Первый раз открывает системный
  диалог выбора пути; последующие сохранения обновляют этот файл.
- `Ctrl+Shift+S` — «Сохранить как» в отдельный `.aclproj`.
- `Ctrl+O` — выбрать сохранённый проект и полностью восстановить монтаж.
  Те же команды доступны через кнопку «Проект» в верхней панели.
- Документ хранит ссылку на видео/аудиоисточник, выбранный поток,
  все аудиофрагменты (порядок дорожек, позиции, длины и обрезку,
  усиление, панораму, Solo/Mute, кривые fade), FX-источники и параметры,
  общие настройки, выделение, положение каретки, масштаб и панели.
- Волны и изображения не встраиваются: ACL пересоздаёт их после открытия.
  Исходные файлы, включая результаты очистки и обработки FX, остаются
  на диске; сохранение проекта **не** заменяет экспорт готового WAV.
- Источники рядом с файлом проекта записываются относительными путями.
  Для переноса проекта скопируйте вместе с ним его медиафайлы.
  Если исходник потерян, открытие предложит найти новое местоположение;
  отмена оставляет открытый проект без изменений.
- При открытии нового проекта несохранённые изменения проверяются заранее.
  Звёздочка/точка рядом с кнопкой «Сохранить» означает несохранённый монтаж.
- Формат версионируется. Неизвестная версия отклоняется с ошибкой,
  существующий файл не заменяется неполной записью.

## Сведение и экспорт

Кнопка «Экспортировать» открывает системный диалог сохранения единственного
стереофайла `.wav` (48 кГц, 24 бит).
Экспорт учитывает все слышимые клипы, Solo/Mute, баланс, громкости,
измененные смещения, разрезы и fade. Если нужен только очищенный звук,
заглушите Original или включите Solo на нужной Clean-дорожке.

Для разделенных клипов из одного файла FFmpeg открывает источник один раз,
а затем применяет `asplit` и `atrim`. Результат дополняется тишиной до
длительности проекта и пишется во временный WAV. Только после успешного
завершения происходит атомарное переименование; исходные дорожки
никогда не перезаписываются.

## Проверка

Из каталога `desktop`:

```sh
npm run test:editor
npm run test:history
npm run test:waveform
npm run test:envelope
npm run test:timeline-scroll
npm run test:fx-clips
npm run test:project
npm run build
```

Из корня проекта:

```powershell
.\.venv\Scripts\python.exe -m unittest discover -s tests -p "test_*.py" -v
```

Эти проверки еще нужно выполнить через локальную машину и подтвердить
настоящий экспорт/прослушивание в Electron. Динамический тест включает
экспорт двух частей одного WAV и проверку заголовка результата.

## Ограничения текущей реализации

История Undo/Redo реализована для операций с клипами и дорожками;
автоматизация
эффектов ключевыми кадрами и time-stretch пока отсутствуют.
Настройки эффектов обрабатываются отдельным проходом FFmpeg, а не
вычисляются в реальном времени для каждого параметра.
При источниках с кодеками, которые HTMLAudioElement не поддерживает,
прослушивание может потребовать создания WAV-прокси.
После изменений запускайте новые проверки через Devbox.

## Дополнения: FX и 8000% масштаба (09.10.2026)

- Горизонтальное масштабирование таймлайна: 100–8000% (Ctrl + колесо или кнопки).
- Регулировка усиления: наведите курсор на аудиофрагмент, шарик следует по X.
  Захват работает по всей ширине нижней зоны (до 30px от нижнего края),
  так что точное попадание в маленький маркер не требуется.
  Двойной щелчок в этой зоне сбрасывает усиление до 0 dB.
- Свойства и эффекты всей дорожки открываются через меню слева;
  свойства отдельного фрагмента через контекстное меню самого клипа.
  Эффекты формируют отдельный WAV только из `sourceStartMs` и `durationMs`
  выбранного фрагмента. Применение и сброс попадают в историю Undo.
- Файл оригинала не перезаписывается. Индикаторы `fx` закреплены за
  обработанными фрагментами и доступны при горизонтальном скролле.
- При работе с устаревшим Python-бэкендом Electron сверяет возможности
  `system.hello`, безопасно перезапускает Python без незавершённых задач и
  проверяет доступность `audio.effects` снова. После изменения Electron main
  или preload требуется полный перезапуск настольного приложения.
- Подписи располагаются у верхней границы клипа и обрезаются многоточием
  только если доступная видимая длина конкретного фрагмента меньше текста.

## Магнитный монтаж (12.10.2026)

- Кнопка **Магнит** в панели инструментов и клавиша **N** включают/выключают привязку.
- При перемещении аудиофрагмента магнит учитывает обе его границы; при подрезке — перемещаемую границу.
- Точки привязки: начало и конец проекта, каретка воспроизведения, границы выделения и границы других аудиофрагментов на любых дорожках.
- Вертикальная пунктирная направляющая показывает фактическую точку стыковки.
- **Alt во время перетаскивания** временно отключает привязку, не меняя режим кнопки.
- Порог привязки составляет 8 экранных пикселей, но не более 500 мс при малом масштабе. Недостижимые границы исходного файла игнорируются.
- Действия остаются недеструктивными и участвуют в истории Undo/Redo как один жест.
- Проверка чистой логики: `npm run test:snapping`.
